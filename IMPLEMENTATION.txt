STAGE 7: NEW CHAT AND CALL UI LOGIC
* Initial state on entering the room: media devices are NOT initialized, video is hidden
* The text chat fills the screen
* The header has a CALL button, disabled by default
* CALL becomes active only when there are exactly 2 users in the room
* System messages are shown in red: Sys: <username> joined the room and Sys: <username> left the room (username from LIBRE443_USERS)
* If one user leaves and only one remains, CALL is disabled again
* All system messages and the UI are strictly in English
* When the first user presses CALL, the second user's button starts blinking
* On answer (pressing the blinking CALL button): WebRTC is initialized, camera and microphone are requested
* Default on connect: video OFF, audio ON
* A video window appears with Video and Audio controls
* CALL changes to HANG UP
* On HANG UP: the connection is closed, media devices are released, video is hidden
* Users stay in the text chat, HANG UP changes back to CALL

CURRENT STATE
* Cover page: index.html "Welcome to the Beauty Forum" with a Login form (Username, Password). Users are defined in the LIBRE443_USERS environment variable (.env in the server root, not in the repository). Cookie based auth, /chat.html is available only after login.
* After login the user joins room "main" automatically, with no room selection or Join button. Camera and microphone are requested right away, WebRTC starts when the second user appears.
* System messages: prefix "Sys:" (not "System"), without the word "User" (for example "Sys: Andrey joined the room", "Sys: Andrey left the room", "Sys: Andrey turned off their video"). Names come from LIBRE443_USERS. UI and console messages are in English.
* Exit button in the chat header opens a confirmation modal (Cancel / Exit). The browser Back button opens the same modal instead of leaving immediately.
* Desktop: header with a gradient background, title and version (version in a smaller font). Video on the left, text chat on the right at full content height. Own video preview 150px.
* Mobile: vertical layout (video on top, chat below), fixed chat height 450px with scrolling, preview 150px. In fullscreen the Video/Audio buttons stay visible (safe area aware).
* Favicon: public/favicon.png, linked in index.html and chat.html.
