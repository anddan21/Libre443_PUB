# Libre443

Защищённое веб-приложение для связи (текст, видео), работающее через стандартный HTTPS (порт 443) для маскировки трафика от систем DPI.

## Структура репозитория

* **IDEA.txt** — концепция проекта и технические требования
* **IMPLEMENTATION.txt** — пошаговый план разработки и текущее состояние
* **libre443-server/** — сервер (Node.js, Express, Socket.IO) и клиентский веб-интерфейс

## Сервер (libre443-server)

* **Точка входа:** корень сайта — маскировочная страница «Beauty Forum» (логин по `LIBRE443_USERS` из `.env`, не из репозитория).
* **Чат и звонки:** после входа пользователь попадает на `/chat.html` (комната «main»), автоматически запрашиваются камера и микрофон; при втором пользователе в комнате устанавливается WebRTC-соединение.
* **Авторизация:** cookie после успешного логина; доступ к `/chat.html` только для авторизованных. Кнопка Exit с модальным подтверждением; кнопка «Назад» в браузере также показывает подтверждение выхода.
* **Интерфейс:** десктоп — видео слева, чат справа на всю высоту; мобильный — вертикальный layout, фиксированная высота чата с прокруткой. Системные сообщения в формате «Sys: …» (имена из `LIBRE443_USERS`). Все строки интерфейса и консоли на английском.
* **Секреты:** пароли пользователей и параметры TURN (`TURN_URLS`, `TURN_USERNAME`, `TURN_CREDENTIAL`) задаются в `libre443-server/.env`. Образец переменных — в `.env.example`.
* **Версия:** в шапке и в API `/api/version`. Favicon: `public/favicon.png`.

## Разработка

Проект инициализирован в феврале 2026 года. Стек: Express, Socket.IO, WebRTC; продакшн — HTTPS, Coturn (TURN через TLS). Подробные этапы и планы — в IMPLEMENTATION.txt.
