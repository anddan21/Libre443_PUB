Project: Libre443
Document created: February 26, 2026

MAIN GOAL
Build a fully independent and secure web app for communication (text, files, video) that cannot be blocked or tracked by standard deep packet inspection (DPI) systems. The app must work directly in the browser, with no extra software or VPN to install.

TARGET AUDIENCE
Users in regions with strict internet censorship who need the simplest possible solution that works out of the box on any device, including iPhone in Safari.

TECHNICAL ARCHITECTURE AND TRAFFIC OBFUSCATION
1. Infrastructure
* Hosting: a cloud VPS (initially Google Cloud) with the ability to change the IP address quickly in case of subnet wide blocking. The best location is Europe, to balance latency.
* Access: a low profile domain name is required to obtain an official trusted SSL certificate (Let's Encrypt). This is critical, otherwise mobile browsers block camera access.

2. Network protocols
* Single port: every connection goes through port 443 only.
* Text and files: signaling and text data exchange run over secure WebSockets (WSS).
* Video and audio streams: WebRTC is used, but direct P2P between users is disabled on purpose. All media traffic is wrapped in a TCP tunnel through a self hosted TURN server (Coturn).
* Encryption: the TURN server runs over TLS. This prevents UDP packet leaks and makes the heavy video stream indistinguishable from loading a heavy web page over HTTPS.

EXPECTED RESULT
A convenient messenger that is invisible to censors. Users open a private web address, enter an access password and get a stable connection with 200 to 300 ms latency.
